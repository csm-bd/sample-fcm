## 📦 Step 2: Change Application Package Name
### 🔄 Change Application Package Name
  - install using this command on your terminal
  <pre> ```bash flutter pub add change_app_package_name ``` </pre>
  - Now Run this command to change the package name for both platforms.
  <pre> ```bash dart run change_app_package_name:main com.your_package_name ``` </pre>
